# crt-cpp-app

`crt-cpp-app` 是一个跨平台的命令行工具，用于快速创建可由 CMake 构建的 C++ 项目。

工具会生成可执行程序、静态库、动态库以及常用的 `inc/`、`res/`、`3rd/`、`patch/` 和 `cmake/` 目录，并支持 C++17 和 C++20。安装完成后，各种发行包都使用相同的命令和参数。

`crt-cpp-app` is a cross-platform command-line scaffolding tool for C++ CMake projects. It interactively creates a ready-to-build project layout with executable, static-library, shared-library, and reusable CMake components, supporting C++17 and C++20. All distribution packages provide the same command and options after installation.
